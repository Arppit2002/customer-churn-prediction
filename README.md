# Customer Churn Prediction Using Logistic Regression

## 1. Project Overview
This project focuses on predicting customer churn using machine learning techniques. The objective was to analyse customer behaviour and identify factors associated with customer attrition.

## 2. Project Objective
- Analyse customer characteristics and subscription behaviour.
- Identify factors influencing customer churn.
- Develop a Logistic Regression classification model.
- Evaluate model performance and derive actionable insights.

## 3. Dataset Description
The project uses customer-level data containing features such as:
- Age and Gender
- Tenure and Usage Frequency
- Support Calls and Payment Delays
- Subscription Type and Contract Length
- Total Spend and Last Interaction

## 4. Tools & Technologies
- **R:** Data preprocessing, exploratory data analysis and Logistic Regression modelling.
- **Orange Data Mining:** Model validation and analytical comparison.
- **Microsoft Excel:** Dataset handling and preparation.

## 5. Methodology
1. Data understanding and exploratory data analysis.
2. Data cleaning and preprocessing.
3. Feature selection and categorical variable encoding.
4. Logistic Regression model development.
5. Model evaluation and validation using Orange Data Mining.

## 6. Project Outcome
Developed a customer churn prediction model using Logistic Regression and examined customer attributes associated with churn.

*Detailed model evaluation metrics and findings are documented in the project report.*
